6. Откройте файл decorators.py. 
   
   6.1 Примените декоратор log его к произвольной функции

   6.2 Если нужен вывод лога работы функции в консоль, параметр декоратора менять не нужно.
   Если нужна фиксация логов в файле .txt укажите название файла в качестве аргумента filename.
   
   Пример работы декоратора:

   ```@log(filename="mylog.txt")
      def my_function(x, y):
          return x + y

      my_function(1, 2)
   ```

    Ожидаемый вывод в лог-файл mylog.txt при успешном выполнении:
    ```my_function ok: 3```

    Ожидаемый вывод при ошибке:
    ```my_function error: тип ошибки. Inputs: (1, 2), {}```
    Где тип ошибки заменяется на текст ошибки.

8. Откройте файл external_api.py
   
   - функция принимает в качестве аргумента данные о транзакции
   - если транзакция в EUR или USD, то производится конвертация в рубли с обращением
   по API к https://api.apilayer.com/exchangerates_data/convert
   
   - пример работы функции: ```33333.00``` - значение в рублях  в формате flat


9. Откройте файл csv_excel_data_upload.py
   
   - Функция csv_data_upload(file_path: str) -> list[dict] считывает данные о финансовых операциях из csv файла.
   В качестве аргумента введите путь к файлу в формате .csv

  - Функция excel_data_upload(file_path: str) -> list[dict] считывает данные о финансовых операциях из excel файла.
   В качестве аргумента введите путь к файлу в формате .xlsx

  - Если файл не найден, пустой или содержит ошибки, функция возвращает пустой список

  - Данные выводятся в виде списка словарей с данными о финансовых операциях


10. Откройте файл search_count_operations.py
   
   - Функция process_bank_search(data_operations: list[dict], search_element: str) -> list[dict] 
   возвращает список словарей, у которых в описании есть заданное слово
   - Данные выводятся в виде списка словарей с финансовыми операциями

   - Функция
   process_bank_operations(data_operations: list[dict], operations_categories: list) -> dict
   возвращает словарь, в котором ключи — это названия категорий, 
   а значения — это количество операций в каждой категории
   - Данные выводятся в виде словаря, где ключ - это названия выбранных категорий, 
   а значение их количество

11. Откройте модуль main.py
   
   Функция main() отвечает за основную логику проекта. В результате интерактивного 
   обмена данных в виде вопросов и ответов возвращается информация о банковских операциях
   в соответствии с выбранными критериями.
