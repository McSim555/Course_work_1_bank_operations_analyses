# Проект 1. Приложение для анализа банковских операций

## Описание: в рамках курсовой работы были реализованы три задачи: Главная из категории Веб-страницы, Выгодные категории повышенного кешбэка из категории Сервисы и Траты по категории из категории Отчёты.

## Установка:

- Клонируйте репозиторий
```git clone https://github.com/McSim555/Course_work_1_bank_operations_analyses```
- Откройте проект bank_application в PyCharm версии >= 3.14

## Использование:

1. Откройте ветку feature/stage_1
``` git branch feature/stage_1 ```

2. Откройте файл viesw.py
   
   Функция main_page принимает аргумент дата в формате YYYY-MM-DD HH-MM-SS 
   и использует вспомогательные функции, написанные в модуле utils.py:

   ```greetings``` определяет формат приветствия в зависимости от времени суток

   ```data_from_excel``` выгружает данные из Excel файла, расположенного в папке ```data``` в корне проекта

   ```cards_data``` формирует выдачу информации об операциях в соответствии с форматом ТЗ

   ```sort_by_payment``` формирует информацию о ТОП5 тратах с начала месяца, на который выпадает входящая дата, по входящую дату

   ```currency rates``` получает информацию по API о курсах валют, указанных в файле ```user_settings.json```, расположенного в корне проекта

   ```stock_information``` получает информацию о стоимости акций компаний, указанных в файле ```user_settings.json```

   Функция ```main_page``` формирует ответ в формате JSON и сохраняет его в папку ```data/json_outputs```

3. Откройте модуль services.py
   
   Функция ```cashback_categories``` принимает путь к файлу с данными, год и месяц, за которые проводится анализ. 
   В файл cashback_by_categories.json в папке data/json_outputs

4. Откройте модуль reports.py

   Функция ```spending_by_category``` принимает данные в виде DataFrame, категорию для отчета и опционально дату и 
   выводит сумму трат за последние 3 месяца по заданной категории. 
   С помощью декораторов отчет записывается в папку ```json_outputs```. 
   My_decorator пишет в spending_by_category.json. My_decorator_with_param в файл, имя которого является аргументом вызова декоратора
